🔌 Cliente MCP de bolso

Esta página faz, passo a passo, o que um assistente de IA faz quando se conecta ao servidor MCP da API (POST /mcp)

🗂️ Cadastro de Tarefas 👥 Responsáveis e vínculo 🤖 Assistente de IA 📘 Swagger UI

1 Conectar (initialize)

O cliente se apresenta e o servidor responde com o nome, a versão, o que sabe fazer (capabilities) e as instruções. O servidor devolve um Mcp-Session-Id: as próximas mensagens levam esse cabeçalho.

Desconectado.

2 Descobrir e chamar ferramentas

tools/list devolve nome, descrição e o formato dos parâmetros (JSON Schema). É com isso que a IA decide o que chamar. Aqui, quem decide é você: preencha e clique em Chamar (tools/call).

3 Ler um recurso

Recurso é um texto que o cliente anexa ao contexto da IA. resources/read com a URI tarefas://regras.

4 Usar um prompt pronto

Prompt é um pedido pronto, com argumentos. prompts/get devolve o texto que iria para a IA.
