🔐 Verificação em duas etapas

Com o 2FA ligado, entrar exige a senha e um código de 6 dígitos que muda a cada 30 segundos no seu celular. Quem descobrir só a sua senha não entra.

Funciona com qualquer aplicativo TOTP: Google Authenticator, Microsoft Authenticator, 2FAS, Authy, FreeOTP, Aegis, o gerenciador de senhas do iPhone...

  1. Abra o aplicativo autenticador e toque em adicionar conta (ou "+").
  2. Leia o QR Code abaixo com a câmera.
  3. Digite o código de 6 dígitos que apareceu no aplicativo.

✅ Ligado. No próximo login, a API vai pedir o código do aplicativo.

Para desligar, confirme a senha e um código. Só o token não basta: se alguém pegar o seu computador aberto, não consegue tirar a proteção.

🔎 O que tem dentro do seu token (JWT)

Um JWT tem três partes separadas por ponto: cabeçalho.conteúdo.assinatura. O conteúdo é só Base64: qualquer um lê (é o que esta página faz, sem chave nenhuma). O que ninguém consegue é alterar: a assinatura deixaria de bater e a API responderia 401.
